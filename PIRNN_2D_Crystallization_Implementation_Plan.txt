1. THE BIG PICTURE IN SIMPLE WORDS
----------------------------------------------------------------------------------------------------
We have a chemical cooling crystallizer growing KDP crystals.
1. The crystals grow in 2 directions: Length (L1) and Width (L2).
2. The population balance is a complex 2D Partial Differential Equation (PDE).
3. Using the 2D Method of Moments (SMOM), we convert that difficult PDE into 7 simple ODEs.
4. We combine these 7 moment ODEs with the Solute Mass Balance ODE (dc/dt) and Temperature.
5. Problem in real plants: The crystal growth rates (kg1, kg2) and nucleation rate (kb) drift or are 
   unknown due to impurities.
6. Our Solution: We use an Inverse Physics-Informed RNN (PI-RNN) to discover the true kinetic 
   rates (kg1, kg2, kb) in real time from sensor measurements, while guaranteeing that mass and energy 
   are strictly conserved.

2. COMPLETE CLASSIFICATION OF ALL VARIABLES & PARAMETERS
----------------------------------------------------------------------------------------------------

[A] DYNAMIC STATE VARIABLES (Change over time during the batch):
-----------------------------------------------------------------
  mu_00 : Total number of crystals
  mu_10 : Total crystal length
  mu_01 : Total crystal width
  mu_20 : Second moment of length
  mu_30 : Third moment of length
  mu_11 : Cross-moment (length x width)
  mu_21 : Volume-related cross-moment
  c     : Solute concentration in liquid (g KDP / g water)
  T     : Solution temperature in crystallizer (°C or K)

[B] KNOWN FIXED CONSTANTS (Assumed constant from literature / Paper 2):
-----------------------------------------------------------------------
  rho_c  = 2.338 g/cm³        : Density of solid KDP crystal
  m_w    = 1000.0 g           : Mass of solvent (water)
  a_i1   = 0.2087             : Solubility polynomial constant 0
  b_i1   = 0.0029             : Solubility polynomial constant 1 (linear T)
  c_i1   = 0.0001             : Solubility polynomial constant 2 (quadratic T²)
  d_i1   = 0.0                : Solubility polynomial constant 3 (cubic T³)
  b      = 1.76               : Nucleation reaction order exponent
  g1     = 1.48               : Growth order exponent for Length (L1)
  g2     = 1.74               : Growth order exponent for Width (L2)
  tbatch = 7200 s (2.0 hours) : Total batch run duration
  T0     = 34.0 °C            : Initial starting temperature
  Tf     = 28.0 °C            : Final target cooling temperature
  c0     = 0.308 g/g          : Initial solute concentration

[C] UNCERTAIN / TRAINABLE PARAMETERS (Discovered by Inverse PI-RNN):
-------------------------------------------------------------------
  These are the parameters that drift in real plants and our PI-RNN will estimate online:
  
  1. kb  (Nominal = 1.0e2)    : Secondary Nucleation kinetic rate constant
  2. kg1 (Nominal = 1.5e-4)   : Length (L1) Growth rate kinetic constant
  3. kg2 (Nominal = 2.8e-4)   : Width (L2) Growth rate kinetic constant

  (In PyTorch, we define them as: self.log_kb, self.log_kg1, self.log_kg2 as trainable parameters).

[D] MANIPULATED / CONTROL INPUT (What the controller operates):
---------------------------------------------------------------
  Cooling Temperature Trajectory: T(t) = T0 - (T0 - Tf) * (t / tbatch)
  (Or Cooling Jacket Flow Rate F_win / Water Temp T_win if dynamic jacket is active).

[E] MEASURED SENSOR DATA (Available in real-time from plant sensors):
---------------------------------------------------------------------
  - Solution concentration: c(t)  (measured via ATR-FTIR or Refractometer)
  - Solution temperature:   T(t)  (measured via Thermocouple / PT100)
  - Seed crystal dimensions at t = 1000s: L1_seed = 100 um, L2_seed = 100 um, Mass_seed = 1.5 g


----------------------------------------------------------------------------------------------------
3. THE 8 CORE GOVERNING EQUATIONS (EXACTLY WHAT WE CODE)
----------------------------------------------------------------------------------------------------

1. Solubility Curve:
   csat(T) = a_i1 + b_i1 * T + c_i1 * T^2

2. Relative Supersaturation:
   S = (c - csat) / csat

3. Nucleation Rate:
   Bnuc = kb * S^b

4. 2D Crystal Growth Rates:
   G1 = kg1 * S^g1    (Growth along Length L1)
   G2 = kg2 * S^g2    (Growth along Width L2)

5. Seven 2D Moment ODEs:
   d(mu_00)/dt = Bnuc
   d(mu_10)/dt = G1 * mu_00
   d(mu_01)/dt = G2 * mu_00
   d(mu_20)/dt = 2 * G1 * mu_10
   d(mu_30)/dt = 3 * G1 * mu_20
   d(mu_11)/dt = G1 * mu_01 + G2 * mu_10
   d(mu_21)/dt = 2 * G1 * mu_11 + G2 * mu_20

6. Solute Mass Balance ODE:
   dc/dt = - (rho_c / m_w) * [ 2 * G1 * (mu_11 - mu_20) + G2 * mu_20 ]

7. Physical Outputs Extracted:
   - Average Crystal Length:  L1_bar = mu_10 / mu_00
   - Average Crystal Width:   L2_bar = mu_01 / mu_00
   - Aspect Ratio (Shape):    AR = L1_bar / L2_bar
   - Total Crystal Mass:      Mc = rho_c * (mu_21 - (2/3) * mu_30)


----------------------------------------------------------------------------------------------------
4. HOW INVERSE PI-RNN LEARNS UNCERTAIN PARAMETERS (THE LOSS FUNCTION)
----------------------------------------------------------------------------------------------------

Total Loss = Data Fitting Loss + Physics Residual Loss

Loss = MSE( predicted_concentration, actual_sensor_concentration )
     + MSE( predicted_temperature, actual_sensor_temperature )
     + gamma * || d(mu)/dt - F_moments(mu, c, T, kb, kg1, kg2) ||^2
     + gamma * || dc/dt - F_mass(mu, c, T, kg1, kg2) ||^2

When you call `loss.backward()`, PyTorch automatically computes:
  - Gradients for Neural Network weights (theta) -> Updates RNN
  - Gradients for (kb, kg1, kg2) -> Discovers the true physical kinetic constants!

5. KEY CLARIFICATIONS & DECISIONS BEFORE STARTING TO CODE
----------------------------------------------------------------------------------------------------

Clarification 1: Chemical System
- Decision: We will use KDP (Potassium Dihydrogen Phosphate) from Section 4 of Paper 2 as the primary 
  benchmark because it has well-established 2D kinetic parameters and clear experimental curves.

Clarification 2: Operation Mode & Seeding
- Decision: Seeded batch cooling operation. 
  * Phase 1 (0 to 1000 s): Cool from 34 °C down to saturation line.
  * Phase 2 (at 1000 s): Introduce 1.5 g seed crystals (L1 = 100 um, L2 = 100 um).
  * Phase 3 (1000 to 7200 s): Controlled linear cooling to 28 °C while seeds grow.

Clarification 3: Primary Uncertainties to Simulate
- Decision: We will simulate realistic batch-to-batch disturbances:
  * Disturbance 1: Solvent impurity poisoning causing Length Growth kg1 to drop by 30%.
  * Disturbance 2: Agitation shift causing Width Growth kg2 to drop by 15% and Nucleation kb to increase by 50%.
  * Our Inverse PI-RNN will be tasked with discovering these exact percentage drops online.

Clarification 4: Neural Network Backbone
- Decision: A lightweight 2-layer GRU (Gated Recurrent Unit) in PyTorch. 
  GRU is preferred over vanilla RNN (better long-term memory) and faster than LSTM (fewer parameters), 
  ensuring online retraining takes < 15 seconds.
